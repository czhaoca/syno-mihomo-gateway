网关洞察（Gateway Insights）
============================

网关洞察是面板的流量视图，也是面板打开时的页面：

      http://<PANEL_IP>:8090/ui/

它展示网络此刻在做什么：在你选择的时间范围内（24 小时、48 小时、7 天、
30 天或长期）的合计、时间线，以及流量最多的设备、类别、出口节点、国家/地区
和主机名。

--------------------------------------------------------------------------
下钻查看
--------------------------------------------------------------------------
点击一行可以查看细节，用视图上方的路径（或浏览器的后退键）返回：

      总览  ->  一台设备  ->  它的某个类别
                          ->  它的某个主机名
      总览  ->  一个类别  ->  使用它的设备
      总览  ->  一个主机名  ->  使用它的设备

页面地址就代表这个视图，所以刷新或书签都会回到这里。「设备」标签页中每台
设备的历史记录都链接到这里。

类别视图无法列出主机名或出口节点：面板把它们分别存储，无法按其中一个拆分
另一个。视图会说明这一点，而不是显示一个空列表。要查看某台设备的主机名，
请回到该设备，再在那里选择主机名。

每个列表显示十个值，并说明没有显示的部分。「显示更多」每次再加十个，最多
200 个。

--------------------------------------------------------------------------
读懂图表
--------------------------------------------------------------------------
      斜线带           采集空档——面板当时没有计数。不是零。
      没有柱子         真实的零——在计数，但没有流量。
      标记线           一天的起始时刻或时区在那里改变了。
      「已过时，自…」  最新的读取失败或仍未应答，或采集器停止了；显示的是最后
                       一次成功的画面。
      底色（30 天、长期）
                       早于 7 天：那里不保留主机名。字节数仍然是真实的。
                       （类别视图中从不出现：其中的一切都长期保留。）
                       在主机名视图中，底色表示那里不保留该主机名的流量：
                       没有柱子表示没有数据，而不是没有流量。

「不可用」表示面板的统计没有响应；「没有流量」表示它响应了，但其中没有数据。
两者绝不相同。

--------------------------------------------------------------------------
主机名默认关闭
--------------------------------------------------------------------------
为了隐私，除非你要求，面板不保留任何主机名。如需把主机名（以及每台设备使用
的具体应用）保留 7 天，请在 .env 中设置：

      PANEL_STATS_DOMAINS=true

然后重新部署。类别、出口节点、国家/地区和每台设备的合计无论如何都会保留。

--------------------------------------------------------------------------
实时吞吐、节点延迟与配额
--------------------------------------------------------------------------
总览还会显示面板从 mihomo 读到的三项内容：

      实时吞吐      勾选之前保持关闭，且只在当前浏览器中记住。显示此刻
                    以及最近一分钟每秒的字节数。其中的任何内容都不会被
                    保存。「已有这么久没有新数据」表示数据流停了；它绝不
                    会把一个冻结的数字当作当前值显示。
      节点延迟      每个策略组当前所选的节点，来自 mihomo 自己做的测试
                    （每 5 分钟采样一次，默认保留 14 天）。斜线标记表示
                    一次失败的测试：没有应答，绝不是 0 毫秒。空白表示那
                    段时间没有测试。
      配额          每个提供者已用的流量相对于总量的比例，以及到期时间，
                    以提供者报告的为准（每小时采样一次）。没有总量就没有
                    进度条。

小组件最新一次读取失败，或采集器已停止时，它会标为已过时，并保留最后一次
正确的画面。

--------------------------------------------------------------------------
面板看不到的流量
--------------------------------------------------------------------------
只统计经过网关的流量。绕过网关的设备（例如通过路由器下发的 IPv6 路由），
或网关之外的 DNS 服务器，都看不到。修复方法见 TROUBLESHOOTING.zh.txt；诊断会检查：

      sudo sh scripts/doctor.sh

--------------------------------------------------------------------------
安全
--------------------------------------------------------------------------
读取面板不需要密码，并会显示每台设备的流量。请让它只在局域网内使用；绝不要
把它的端口转发到公网。
