# v1.13.0 — Gateway Insights: the Insights screens (DRAFT until tagged)

The third slice of Gateway Insights, and the one you see. The panel's
landing tab is now **Insights**. You can drill from the whole gateway into
one device, then into one of its categories or hostnames, and every view
says how far its numbers can be trusted.

## What's new

- **The Insights tab** (formerly Stats). One view, four scopes:
  - the **overview** (the whole gateway);
  - a **client** (one device);
  - a **category**;
  - a **host** (one hostname).

  Each scope shows totals, a timeline and the top lists of the next level.
  - **Drilling.** A row drills into the next scope, and the trail above
    the view leads back. From a device, its categories and hostnames drill
    further while the device is kept.
  - **The address is the view.** The route lives in the page address
    (`#/insights/client/<ip>?range=30d`), so the back button, a reload and
    a bookmark keep it.
  - **The Devices tab** links each host's history to its client scope.
  - **What a scope cannot answer is said.** The panel stores each
    dimension separately, so a category scope cannot list hostnames or
    exit nodes. The view names those lists and says why; it never shows
    them empty or as zero.
- **Top lists** show ten values, say how many values and bytes they left
  out, and grow ten at a time up to 200 with "Show more".
- **Charts drawn by the panel itself**, with no chart library:
  - a collection gap is a hatched hole, never a zero;
  - a missing bar with no gap is a real zero;
  - a moved day boundary is a marked seam;
  - a picture whose newest read failed stays on screen, marked "stale
    since" the poll it includes;
  - "unavailable" (the store did not answer) is never drawn as "no
    traffic".

  Bars can be read by pointer, by touch or with the arrow keys.
- **The hostname window.** On 30 days and long term, the span older than
  seven days is shaded. Its bytes are real; the shade marks that
  hostnames, app-level ids and the attribution split are not kept there.
- **Notes:**
  - hostnames being off, with how to turn them on;
  - what the gateway cannot see (devices or DNS that bypass it, such as an
    IPv6 route);
  - the attribution share, with the window it was measured over.
- **A 24-hour range** beside 48 hours, 7 days, 30 days and long term. It is
  accepted by the `stats_default_range` setting and the API's `range=`.
- **Dark mode.** A System / Light / Dark picker sits beside the language
  toggle. On System it follows the device, live.

## What changes for you

- **The panel opens on Insights.** Old links to `/ui/` still work and land
  on its overview.
- **One stats read per refresh.** The tab now reads only
  `/v1/stats/overview`, where the Stats tab used to read six endpoints.
  The re-read follows the view's resolution:
  - minute views every 10 s;
  - hour views every 60 s;
  - day views every 300 s.

  It never reads while the tab is hidden, and the refresh never starts a
  read beside one in flight: a read unanswered for two refresh periods
  marks the picture stale instead. Until a view has its first answer, it
  retries every 10 s.
- **API:** `/v1` is additive. `range=24h` is new on every stats read that
  takes `range`, and nothing else changes.

## Downgrading, or an automatic rollback

v1.13 changes neither database. The stats schema is unchanged, so an older
panel opens it as it is. The UI ships inside the panel image, so an older
image serves its own UI. An older panel that reads a stored `24h` default
range lands on its own default, because reads never re-validate a stored
setting.

## Upgrading

Deploy the new panel image and recreate the panel container. No `.env`
change and no migration are needed. An image that has not been republished
keeps serving the old panel, because the UI ships inside it.

## Validation notes

`validate_release.sh` phases **A6 and A6c are required gates**, on a panel
image built from the tag. In addition, record from the NAS during the run:
- `GET /v1/stats/overview?range=24h` answers 200 with `totals.tier` equal to
  `minute`.
- In a LAN browser, the panel opens on Insights. A device row drills to its
  client scope, and a category drills from there. A reload keeps the view.
- The scheme picker switches the panel between light and dark.

Carry any change the v1.11 or v1.12 validation required into this release
before it is tagged (the #96 REQ-ADD poll default).
